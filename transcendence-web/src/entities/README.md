# src/entities

## Cel folderu
Warstwa kontraktow i bazowych implementacji encji swiata gry.

## Co zawiera
- base/: typy i klasy bazowe encji (kategorie, interfejsy, manager, klasa bazowa).

## Zaleznosci zewnetrzne i wewnetrzne
- Zewnetrzne: brak.
- Wewnetrzne: wykorzystywane przez src/app oraz src/presentation.

## Jak uzywac
Importuj elementy bazowe przez @entities/base.

## Dokumentacja plikowa
- Opisy plikow sa obok kodu, glownie w src/entities/base jako pliki *.md.

## Czego NIE robi
- Nie zawiera konkretnej logiki statkow/NPC.
- Nie implementuje systemow gameplay.
