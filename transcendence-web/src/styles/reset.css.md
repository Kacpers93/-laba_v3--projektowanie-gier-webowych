## Cel pliku
Plik ustawia bazowy reset layoutu: box-sizing, pelny rozmiar roota i brak marginesow. Wymusza tez czarne tlo i ukrycie overflow dla body.

## Co eksportuje
Plik niczego nie eksportuje (arkusz CSS).

## Zaleznosci zewnetrzne i wewnetrzne
- Zewnetrzne: CSS w przegladarce.
- Wewnetrzne: ladowany przez src/main.ts.

## Jak uzywac (minimalny przyklad)
```ts
import '@/styles/reset.css';
```

## Czego NIE robi
- Nie styluje konkretnych warstw aplikacji.
- Nie definiuje styli panelu deweloperskiego.
