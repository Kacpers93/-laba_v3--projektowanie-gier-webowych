Pliki PNG sprite'ow wrót wykorzystywanych przez manifest assetow.

## Co zawiera
- Pliki obrazu gate/jumpgate wskazywane przez wpisy URL w asset-manifest.json.

## Zaleznosci zewnetrzne i wewnetrzne
- Zewnetrzne: brak.
- Wewnetrzne: public/art/asset-manifest.json oraz src/presentation/assets/AssetLoader.ts.

## Jak uzywac
