# public/art/stations

## Cel folderu
Pliki PNG sprite'ow stacji wykorzystywanych przez manifest assetow.

## Co zawiera
- Pliki obrazu stacji (np. trading-outpost, mining-platform) referencjonowane w asset-manifest.json.

## Zaleznosci zewnetrzne i wewnetrzne
- Zewnetrzne: brak.
- Wewnetrzne: public/art/asset-manifest.json oraz src/presentation/assets/AssetLoader.ts.

## Jak uzywac
Pliki sa ladowane pośrednio przez URL wskazane w /art/asset-manifest.json.

## Dokumentacja plikowa
- Pliki PNG sa binarne i nie maja indywidualnych plikow .md.

## Czego NIE robi
- Nie zawiera kodu runtime.
- Nie zawiera mapowania kategorii assetow.
