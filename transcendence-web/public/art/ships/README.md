# public/art/ships

## Cel folderu
Pliki PNG sprite'ow statkow wykorzystywanych przez manifest assetow.

## Co zawiera
- Pliki obrazu statkow (np. scout i freighter) wskazywane przez pola url w asset-manifest.json.

## Zaleznosci zewnetrzne i wewnetrzne
- Zewnetrzne: brak.
- Wewnetrzne: public/art/asset-manifest.json oraz src/presentation/assets/AssetLoader.ts.

## Jak uzywac
Folder jest uzywany posrednio przez wpisy url w /art/asset-manifest.json.

## Dokumentacja plikowa
- Pliki PNG sa binarne i nie maja indywidualnych plikow .md.

## Czego NIE robi
- Nie zawiera kodu TypeScript.
- Nie zawiera konfiguracji manifestu.
