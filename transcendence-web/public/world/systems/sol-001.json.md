## Cel pliku
Plik zawiera seed startowego systemu Sol uzywany przy uruchamianiu runtime. Definiuje obiekty systemu, granice oraz grupy asteroid.

## Co eksportuje
Plik niczego nie eksportuje (plik danych JSON).

## Zaleznosci zewnetrzne i wewnetrzne
- Zewnetrzne: brak.
- Wewnetrzne: odczytywany przez src/world/seed/SystemSeedLoader.ts; walidowany przez src/world/seed/validateSystemSeed.ts; grupy asteroid rozwijane przez src/world/seed/expandAsteroidGroups.ts.

## Jak uzywac (minimalny przyklad)
```ts
const result = await systemSeedLoader.loadSystem('/world/systems/sol-001.json');
```

## Czego NIE robi
- Nie oblicza pozycji obiektow w runtime.
- Nie zawiera kodu wykonawczego ani eksportow TypeScript.
